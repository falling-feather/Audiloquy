English Listening Prototype - local development build

This application uses dynamically linked Qt 6 and runtime libraries from MSYS2 UCRT64.
The binary distribution includes their license texts under licenses/ and an
exact package/version/source index in licenses/runtime-dependencies.json.
DLLs remain separate and replaceable; modifications to these libraries may be
used with the application, subject to their respective licenses.
Qt is available under commercial and open-source licensing options. The local
build currently uses the open-source distribution; see:
https://doc.qt.io/qt-6/licensing.html

The packaged directory also contains compiler/runtime dependencies copied from
the MSYS2 UCRT64 toolchain. Their license texts and corresponding source package
information are available from the MSYS2 package repository:
https://packages.msys2.org/

Windows Speech API and WinMM are operating-system components and are not
redistributed by this project.

Windows Media Foundation is also an operating-system component, not redistributed.

The optional Kokoro pack is downloaded separately from pinned upstream releases.
Kokoro weights: Apache-2.0; sherpa-onnx runtime includes additional third-party
components including GPL phonemization code. Those executables are not linked
into or included in the base application archive. Their source and notices are
listed by the installer in the independent voice-pack directory.

Audiloquy is a development/test release. Its own source has no general-purpose
open-source license assigned; third-party components retain their licenses.
