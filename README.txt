Audiloquy / 语澜 — 英语听力生成与课堂播放原型
=================================================

快速开始

1. 双击 Audiloquy.exe。
2. 从空白工程开始，新增题组并填写文稿；可复制、删除、拖动排序，或打开示例。题组操作支持撤销和重做，排序保留原题号。
3. 情景生成器默认使用本地规则；需要时可主动选择 DeepSeek 润色。无论来源如何，都要先核对答案证据，再采用到当前题组。
4. 在右侧选择 en-US/en-GB、目标 WPM，以及男声和女声。程序会显示本机实际安装的匹配结果。
5. 点击“生成并试听选中题组”或“生成并播放整套”。音频在后台生成，可查看进度或取消；生成期间锁定编辑，完成后自动试听。
6. 在底部播放器使用上一组、播放、暂停/继续、拖动定位、循环、停止和下一组。
7. “打包带走”会创建含 project.json 和音频的独立文件夹；复制整个文件夹到教室电脑，在语澜中打开 project.json 即可播放。

保存、恢复与重复生成

- 未填完的草稿也可保存；写入失败不会先清空原工程文件。
- 编辑期间每 3 秒尝试保存独立恢复草稿。异常退出后下次启动可恢复或丢弃，其他仍在运行的会话不会被当成异常草稿。
- 音频缓存按文稿、实际音色和语速区分。只调整停顿、重复次数或题号时复用已有语音，不再重新朗读全文。
- 每遍朗读后都会保留设定的停顿，包括最后一遍。取消保留已经完整生成的题组，不发布半成品整套音频。
- 打包的是工程与已生成音频，不包括系统声音、本地模型、缓存或 API 密钥；换电脑播放不需要重装原音色，重新生成则需要该电脑有匹配声音。

文件位置

- 如果工程尚未保存，结果写入程序当前工作目录下的
  ListeningStudioResults/<工程ID>/。
- 如果工程已经保存，结果写入工程 JSON 文件旁的 <工程名>_audio/。

声音与口音

- 男、女台词会逐轮分别合成，MAN:/WOMAN: 标签不会被朗读。
- 默认启用“严格口音”；目标 locale 或目标性别没有实际安装时，程序会明确阻止生成，不会把美音冒充英音、把女声冒充男声。
- 如课堂临时需要，可主动开启“允许性别回退”；界面和生成结果仍会标出实际采用的 voice。
- 基础发行包使用 Windows SAPI 系统音色。自然度、口音真实性和可选男女声取决于电脑实际安装的语音；“系统音色”不等同于神经网络真人音色。
- 当前开发机只检测到 Microsoft Zira Desktop（en-US，女声），没有 en-US 男声或 en-GB 英语音色。要获得真实双人/英式播音，可安装相应 Windows 语音，或使用“打开声音包目录”放入自行完成许可与听审的本地神经声音包。
- 外置声音包位置为 %LOCALAPPDATA%\Audiloquy\voice-packs\*.voice-pack.json；协议和 helper 参数见源码包 voice-packs\README.txt。基础发行包不会捆绑许可未核清的运行时或模型。

本地生成与可选 DeepSeek

- 默认流程是完全本地、确定性的 When / Where / Why / What 初稿，不需要账号或网络。
- 主动选择 DeepSeek 时，题干、选项、答案、主题和完整本地初稿会发送给该服务；界面会如实提示这一范围。
- DeepSeek 可以自然化全部轮次，但必须为每个选项回传保留选项事实的精确证据片段；本地端会重建字节位置并复核支持/排除关系。失败时继续保留本地草稿。
- “结构与事实锚点通过”不等于机器已经证明答案语义唯一；采用后可在专业模式勾选教师确认，确认状态会随工程保存。
- 可选密钥读取顺序：环境变量 DEEPSEEK_API_KEY；%LOCALAPPDATA%\Audiloquy\deepseek.txt；当前工作目录或程序目录下的 .private\deepseek.txt。
- 密钥只放一行，不要添加引号。发布目录和 ZIP 不包含密钥；请勿把 .private 目录提交或发送给他人。

其他说明

- 界面提供简洁/专业模式，并使用与项目配色统一的无边框窗口和提示框。
- schema 2 工程会保存男女声音 token、严格口音/性别回退、生成来源/模型/证据/教师审阅状态和 WAV 引用；相对音频路径以工程文件所在目录解析，旧绝对路径和 schema 1 工程仍可读取。
- 自动初稿、模型润色和答案证据必须由英语教师复核后再用于正式教学或考试。
- 按 Esc 可随时停止播放。

这是开发原型，尚无正式版本号。
